01. About

Background & Architecture Philosophy

Why I build AI the way I do: making autonomous systems predictable, verifiable, and resilient.

I am an engineer with an Integrated M.Tech in Computer Science & Engineering from Vellore Institute of Technology (Amaravati). Over the last five years of building distributed software and AI architectures, I noticed a fundamental gap: most modern GenAI breaks down the second it meets messy real-world data.

Calling an LLM API takes 5 lines of code. But building an enterprise system that operates 24/7 requires solving real engineering problems: preventing token memory leaks, eliminating hallucinations on numerical data, and surviving database schema changes without crashing.

My engineering centers on multi-agent architectures using LangGraph, dense + sparse hybrid retrieval (ChromaDB + BM25 with Reciprocal Rank Fusion), and upstream open-source contributions to industry-standard frameworks like LangChain, CopilotKit, and OpenHands.

🤝

Multi-Agent Coordination

Instead of overloading one massive prompt, I coordinate teams of focused subagents with isolated scratchpads and clear supervisor contracts.

🔎

Zero Guesswork Retrieval

I combine semantic vector search with exact keyword matching so precise serial numbers, dates, and metrics are never lost in the noise.

🛡️

Autonomous Self-Healing

When an agent hits a database error or unexpected payload, it diagnoses the traceback, corrects its own query, and resumes without failing silently.

Multi-Agent Research Architecture

DeepScope

View Repository ↗

Single-prompt AI fails on complex research because context windows fill up with messy raw search results. DeepScope solves this by deploying a digital research team: a Lead Coordinator decomposes the question, 4 Parallel Web Agents scour the internet and save data to isolated disk files (preventing memory leaks), and an independent Fact Verifier cross-checks claims before generating publication-grade markdown reports.

Enterprise Hybrid Search Engine

NexusRAG

🚀 Launch Live Demo ↗ View Repository ↗

Standard AI search engines rely only on semantic vector matching, which notoriously overlooks critical exact keywords like account numbers, dates, or financial totals. NexusRAG implements a production-grade dense + sparse hybrid retrieval pipeline fusing ChromaDB semantic vectors and BM25 exact keywords via Reciprocal Rank Fusion, reranked by FlashRank in under 35ms.

Self-Healing Agentic Analytics

E-commerce AI Analytics

🚀 Launch Live Demo ↗ View Repository ↗

Traditional text-to-SQL agents break the moment they encounter unusual schemas or typos, showing users frustrating red error banners. This system introduces an autonomous self-healing StateGraph: when a query fails, the agent intercepts the SQLite traceback, queries database table pragmas, repairs the SQL query in real time, and executes cleanly—all protected by Meta Prompt Guard 86M against SQL injection.
