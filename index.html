Multi-Agent Research

DeepScope

GitHub →

The problem: Ask a chatbot a complex research question and it either gives a shallow summary or makes things up because it tries to process too much information at once.

My solution: DeepScope works like a small research team. A lead coordinator breaks the question into focused tasks, assigns them to specialist AI agents who search the web and store their findings in files (keeping their memory clean), then a fact-checker verifies everything before generating the final report.

Team of AI Agents Web Research Fact Checking Auto Report Writing
Built with Python · LangChain Deep Agents · LangGraph
Document Intelligence

NexusRAG

Live Demo ↗ GitHub →

The problem: Upload a document to ChatGPT and ask for a specific number (like a GPA or revenue figure) — it often gets it wrong because it only searches by meaning, not by exact words.

My solution: NexusRAG uses a dual search strategy — searching by both the meaning of your question AND the exact keywords. A secondary AI re-scores the results for relevance, and every answer includes the exact page number so you can verify it yourself.

Upload & Chat with Docs Dual Search Strategy Page-Level Proof Instant Answers
Built with Python · ChromaDB · BM25 · FlashRank · Groq · Streamlit
Business Analytics

E-commerce AI Analytics

Live Demo ↗ GitHub →

The problem: Store owners need answers about their sales data but don't know SQL. And when basic AI-to-SQL tools make a mistake, they just show an error message with no recovery.

My solution: Ask any business question in plain English — the AI writes the database query, runs it safely, and if a mistake occurs, it automatically figures out what went wrong and fixes the query itself. Then it creates clean charts and actionable business tips.

Ask in English Self-Fixing Queries Auto Charts Safety Protected
Built with LangGraph · Google Gemini · Groq · SQLite · Streamlit
