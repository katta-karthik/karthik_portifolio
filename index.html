Multi-Agent Research System

DeepScope

Source Code →

Conventional chatbots attempt to answer complex research questions in a single pass — cramming thousands of words into their context window until they lose focus, hallucinate, or produce superficial summaries. DeepScope takes a fundamentally different approach by decomposing research into a coordinated multi-agent workflow.

A lead coordinator agent creates a structured investigation plan and delegates focused subtasks to specialized researcher agents. Each agent searches the web independently, persisting its raw findings to a disk-backed workspace rather than holding everything in memory. A dedicated fact-verification agent then audits the collected evidence for gaps and unsupported claims before the system synthesizes a comprehensive, citation-grounded Markdown report.

Advanced RAG Platform

NexusRAG

Live Demo ↗ Source Code →

Standard vector-only retrieval systems consistently fail on precision-dependent queries — ask for a specific GPA, a financial figure, or an exact date, and the system often returns semantically similar but factually incorrect content. NexusRAG addresses this through a complete retrieval-augmented generation lifecycle with a dense-sparse hybrid search architecture.

Documents pass through a visual 7-stage ingestion pipeline (parsing, cleaning, recursive chunking, embedding, hybrid indexing, and AI-powered question synthesis). At query time, the system fuses results from ChromaDB vector search and BM25 lexical matching using Reciprocal Rank Fusion, then applies FlashRank cross-encoder reranking to surface the most relevant evidence. Every response includes verified page-level citations.

Agentic Data Analytics

E-commerce AI Analytics

Live Demo ↗ Source Code →

Typical text-to-SQL implementations are fragile single-shot pipelines — the moment a column name is misspelled, a table alias is wrong, or a syntax error occurs, the system returns a cryptic database traceback and the user is stuck. This project re-imagines text-to-SQL as a stateful, self-healing agent.

Built on a LangGraph StateGraph, the agent plans structured queries, executes them within a strict read-only SQLite sandbox (protected by Meta Prompt Guard 86M), and upon failure, enters an automated diagnosis-and-repair loop that inspects the error, identifies the root cause, and rewrites corrective SQL. Successful results are synthesized into executive-ready response cards with autonomous chart generation.
