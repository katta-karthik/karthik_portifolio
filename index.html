DeepScope — Autonomous Deep Research Agent

Python · LangChain Deep Agents · LangGraph
GitHub ↗

The Problem: When you ask standard AI chatbots complex questions (like "Compare the top 3 approaches for RAG reliability with trade-offs"), they usually give short, superficial summaries or get confused and make up facts.

How it works: DeepScope works like an automated research team. A lead coordinator creates an investigation plan and delegates topics to specialized subagents. These subagents browse the web, write detailed notes to files on disk (keeping memory clean), double-check their facts with a verifier agent, and generate a verified, publication-grade research report.

Multi-Agent System Fact Verification Disk Workspace Deep Research

NexusRAG — Document Search & QA Platform

Python · ChromaDB · BM25 · FlashRank · Groq · Streamlit
Live Demo ↗ GitHub ↗

The Problem: Regular document search with AI often misses exact figures (like a specific grade, date, or revenue number) because it only searches by conceptual meaning rather than exact words.

How it works: NexusRAG allows you to upload any document (PDF, resume, or report) and chat with it. It uses hybrid search — combining conceptual search with exact keyword search — and cross-grades the matches so answers are instant, reliable, and backed up with exact page citations.

Document Search Hybrid Retrieval Exact Citations Fast Groq Inference

E-commerce AI Analytics — Self-Healing Data Analyst

LangGraph · Gemini Flash · Groq · SQLite · Streamlit · MCP
Live Demo ↗ GitHub ↗

The Problem: Non-technical store owners usually have to wait for a database specialist just to see basic sales numbers or customer trends.

How it works: The store owner asks a question in plain English (e.g. "Which products brought in the highest revenue?"). The AI turns the question into a database query, runs it safely, and if a syntax or column error occurs, it diagnoses the error and rewrites the query itself, returning clean charts and business recommendations.
