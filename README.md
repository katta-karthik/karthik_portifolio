## 🚀 How to Enable GitHub Pages (Free Live Hosting)

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: launch portfolio website"
   git branch -M main
   git remote add origin https://github.com/katta-karthik/karthik_portifolio.git
   git push -u origin main
   ```

2. Go to your repository on GitHub:
   - Navigate to **Settings** $\rightarrow$ **Pages** (under the "Code and automation" section in the left sidebar).
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Under **Branch**, select **`main`** and **`/ (root)`**, then click **Save**.

3. In ~60 seconds, your site will be live at:
   👉 **`https://katta-karthik.github.io/karthik_portifolio/`**
